GitHubga Loyiha Yuklash

Kodingizni GitHub repozitoriysiga tez va oson joylashtirish qo‘llanmasi

1

Gitni ishga tushirish

Loyiha papkasida terminalni oching va quyidagi buyruqni yozing:

git init
2

Fayllarni qo‘shish

Barcha fayllarni yuklashga tayyorlash (staging) uchun:

git add .
3

Saqlash (Commit)

O‘zgarishlarga izoh yozib saqlang:

git commit -m "Birinchi yuklash"
4

GitHubga ulash va yuborish

GitHub repozitoriy manzilini ulang va fayllarni yuboring:

git branch -M main
git remote add origin https://github.com/username/repo.git
git push -u origin main
